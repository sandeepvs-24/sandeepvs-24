## Projects

### CropSense AI

**Early detection and management of crop diseases and pest infestations.**

CropSense AI is an agriculture-focused project that combines software, hardware, AI concepts, and smart monitoring.

The idea is to help monitor crop conditions and provide useful information for detecting diseases and pests at an early stage.

#### Features

* AI-based crop disease detection
* Pest detection
* Crop health monitoring
* Treatment recommendations
* Soil moisture monitoring
* Temperature monitoring
* Humidity monitoring
* Smart irrigation
* Pump control
* Mobile dashboard
* Detection history

#### Hardware

* Arduino UNO
* Capacitive soil moisture sensor
* DHT11
* Relay module
* Water pump
* ESP-01
* Potential solar power integration

#### Software

* Flutter
* Dart
* AI/ML concepts
* Mobile application development
* Sensor data monitoring

My main contribution is focused on the **Flutter application and software side** of the project.
